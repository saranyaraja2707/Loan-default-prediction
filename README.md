# Loan-default-prediction
Loan Default Prediction &amp; Risk Analysis | Python, Pandas, Scikit-learn, Matplotlib/Seaborn
Analyzed a 255,000-record loan dataset to identify key drivers of borrower default,
  using Python (Pandas, Scikit-learn) for data cleaning, encoding, and exploratory analysis
Performed descriptive and segmented analysis (by age, income, employment type, loan
  purpose) to uncover default rate patterns across borrower segments
Identified top predictors of default (age, interest rate, income, loan amount) through
  feature importance analysis, providing actionable insight for credit risk assessment
